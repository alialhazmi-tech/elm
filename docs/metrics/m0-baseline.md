## منهج القياس

- JavaScript: مجموع gzip لكل `<script src>` في HTML المولد، ويشمل `nomodule` بصورة محافظة، عبر `npm run budget`.
- HTML: حجم `.next/server/app/index.html` بعد build.
- الأمان وSEO وdeduplication: اختبارات عقد على HTML وroutes manifest.
- لا يُستخدم قياس localhost لإثبات هدف TTFB أو Core Web Vitals الإنتاجي.
