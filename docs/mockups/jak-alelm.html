الصورة تذوب في الخلفية

الخلفية المولدة تملأ الشريحة كاملة، وسكريم مداد مدمج يذيب أطرافها في لون الأساس ويضمن تباين النص — الصورة والنص طبقة واحدة، لا «صورة وتحتها كلام». برومبت التوليد يُوجَّه لمشاهد جوية atmospheric بلا نصوص داخل الصورة.

full-bleedسكريم CSS لا فوتوشوب
الرقم يعدّ نفسه

عداد يصعد من الصفر عند دخول الشريحة (73% جربها فوق)، بتدرج ذهبي داخل الرقم نفسه وحلقة ضوئية تدور خلفه. أشرطة المقارنة تنمو والرقم الثاني يعدّ أيضًا. prefers-reduced-motion يعرض القيم النهائية ساكنة.

لا أبيض إطلاقًا

القصة كلها تعيش على المداد وتدرجاته — القوائم والخلاصات بطاقات زجاجية شفافة، والتسلسل الزمني خط ذهبي متوهج. هوية «العلم» الليلية من أول تمريرة لآخرها.

طباعة إبداعية لا مقالية

كلمة مفتاحية واحدة في كل عنوان تشتعل بالذهب، رقم المحور يطبع ضخمًا شفافًا خلف النص، والعناوين ≤10 كلمات (قاعدة الدستور).

التقاط مرن لا سجن

scroll-snap proximity — التمريرة تستقر والسريعة تمر بحرية، ولا JavaScript يعترض التمرير. شريط تقدم ذهبي أعلى الشاشة + نقاط جانبية.

HTML دلالي كامل

خلف الإبهار البصري صفحة حقيقية: عناوين هرمية ونصوص قابلة للنسخ والفهرسة، وتُقرأ طبيعيًا بلا JavaScript (تختفي الحركة فقط). العميل الوحيد: مراقب تقاطع + عداد ~1.5KB.

القرارالاختيار
الهوية في النموذج«جاك العلم» شكل format: "jakalelm" على جدول المواد نفسه — الاسم الذي حجزه فريق ووردبريس القديم (تصنيف فارغ، صفر مواد). لا قسم جديد ولا خلط بين المحورين.
الرابط العامنفس البنية المقدسة /{section}/{id}/{slug} — صفحة المقال تكتشف الشكل وتعرض قالب جاك بدل قالب المقال. صفر مسارات جديدة.
الشرائحجدول جديد story_slides: أعمدة مكتوبة للحقول الحية (النوع، الترتيب، العنوان، النص، الرقم، الخلفية، سياق المصدر، الإخفاء) + jsonb data لتفاصيل النوع. لا JSON عملاق ولا عشرات الجداول.
الحوكمة مجانًالأن التقرير مادة: سير العمل والحارس عند الإرسال/النشر/الجدولة/لحظة الموعد، والأدوار، والإبطال الفوري، وSEO — موروثة بلا مسار موازٍ. stories.body يُبنى آليًا كنص مجرد من الشرائح فيعمل الحارس والبحث كما هما.
صدق الأرقاممدقق برمجي (لا ذكاء) يرفض أي رقم في الخطة غير موجود حرفيًا في المصدر، وكل شريحة تحمل sourceContext — المقطع الأصلي الذي جاءت منه.
الخلفيات المولدةImagen الحالي بأنماطه الثلاثة وdont_allow للأشخاص؛ البرومبت يُوجَّه لمشاهد جوية بلا نص داخل الصورة، والسكريم المذيب طبقة CSS فوقها — فتغيير الهوية مستقبلًا لا يمس الصور المخزنة. توليد مستقل لكل شريحة، والمكتبة الموثقة بديلًا، وتدرجات الهوية عند غياب الصورة.
الميزانيةالقارئ Server Components + CSS؛ العميل الوحيد مراقب تقاطع وعداد أرقام (~1.5KB مضغوطًا). محرر الشرائح client داخل اللوحة كباقي شاشاتها.
٨ — المخاطر وكيف يطفئها التصميم

ما الذي قد يكسر التجربة؟

هلوسة الأرقام

مدقق برمجي صارم يرفض الخطة إن حملت رقمًا غير موجود في المصدر + عرض «من المصدر» في كل شريحة للمراجعة البشرية.

نص فوق صورة = تباين هش

السكريم المداد إلزامي في القالب نفسه لا في الصورة — النص دائمًا على منطقة معتمة مضمونة، مهما جاءت الصورة فاتحة.

كثرة الصور = بطء

توليد مستقل لكل شريحة، تحميل كسول للبعيد، أبعاد محجوزة، وتدرجات الهوية تحمل الشريحة عند غياب الصورة.

سجن التمرير

proximity لا mandatory، ولا JavaScript يعترض العجلة — التجربة تتحسن بالالتقاط ولا تُفرض به.

تسرب المسودات

المعاينة داخل اللوحة بجلستها فقط؛ المزود العام يفلتر المنشور كما هو اليوم.

إفراط الذكاء

عمليات محددة النطاق لكل شريحة، وإعادة بناء الخطة كاملة خلف تأكيد صريح يحذر أنها ستقترح بنية جديدة.

بانتظار اعتماد المالك — النسخة الغامرة

التغيير عن النسخة الأولى: الصور خلفيات كاملة تذوب في المداد والنص فوقها، أرقام تعدّ نفسها بتوهج ذهبي، أشرطة مقارنة تنمو، ولا خلفية بيضاء واحدة في تجربة القارئ.
