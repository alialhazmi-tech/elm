2. نموذج المحتوى الجديد: تفكيك الأبعاد الأربعة

في النظام القديم تداخلت الأقسام والوسوم؛ أما في منصة «العلم» تم تفكيكها بدقة إلى 4 أبعاد مستقلة ونظيفة:

1. الموضوع Section
تخصص موضوعي صريح واحد للمادة (محليات، اقتصاد، تقنية، علوم، صحة، رياضة، ثقافة...).
2. العدسة Series
عدسة المعرفة السلسلية الثمانية (أبسط، بالأرقام، افهمها صح، لماذا، شخصيات، ماذا لو...).
3. الشكل Format
شكل القالب التحريري (خبر، إنفوجرافيك تفاعلي، مرئي، تقرير جاك العلم، بودكاست).
4. سير العمل Status
دورة حياة المادة والاعتماد (draft → review → scheduled → published) محكومة بالحارس.

5. استراتيجية حماية الـ SEO وصفر فقدان (Zero-SEO-Loss)

تطابق الروابط بنسبة 100% URL Match
بنية الروابط مطابقة تماماً للأرشيف القديم: https://alelm.net/{section}/{id}/{slug} مما يضمن استمرار تدفق زوار Google دون أي انقطاع.
طبقة التحويلات 301 الذكية Wildcard 301
قاعدة «المعرّف ID يحسم»: أي طلب يطابق /*/:id/* يتم التعرف عليه وتوجيهه فوراً بتحويل 301 دائم إلى مساره الصحيح.
ضمان البيانات المهيكلة (Schema JSON-LD) وخرائط الموقع: توليد تلقائي لمخططات NewsArticle و BreadcrumbList لكل مادة لتعزيز الترتيب في Google News، مع خريطة موقع لحظية sitemap-news.xml للأخبار خلال 48 ساعة.
