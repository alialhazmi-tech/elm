2. نموذج المحتوى الجديد: تفكيك الأبعاد الأربعة

شكل القالب التحريري (خبر، إنفوجرافيك تفاعلي، مرئي، تقرير جاك العلم، بودكاست).

دورة حياة المادة والاعتماد (draft → review → scheduled → published) محكومة بالحارس.

3. خريطة مطابقة الحقول (Field Mapping Matrix)

حقل ووردبريس القديم مخطط قاعدة بيانات العلم (Postgres) آلية المعالجة والتحويل الهندسي
ID (المعرف الرقمي) stories.id يُحفظ المعرف الرقمي كما هو حرفياً (مفتاح بقاء الروابط والأرشفة)
slug (الاسم اللطيف) stories.slug تنظيف الترميز العربي والإبقاء على البنية النصية للروابط
title.rendered stories.title فك كيانات HTML وتطهير العنوان وضبطه وفق سقف الـ 10 كلمات
content.rendered stories.body تجريد أكواد Oxygen القصيرة إلى كتل فقرات وHTML دلالي نظيف
excerpt.rendered stories.excerpt تجريد الوسوم وتوليد مقتطف تحريري دقيق ومركز
categories (التصنيف) stories.section التحويل إلى الأقسام الـ 15 المعتمدة مع إعطاء الأولوية للقسم الموضوعي
tags (الوسوم) stories.seriesSlug استخلاص وسوم السلاسل الثمانية الرسمية وعزل الوسوم الملوثة للأرشيف
featured_media stories.image + media تحويل الصور وحفظ الأبعاد الأصلية وتوليد صيغ WebP على Cloudflare R2

4. استراتيجية حماية الـ SEO وصفر فقدان (Zero-SEO-Loss)

تطابق الروابط بنسبة 100% URL Match
بنية الروابط مطابقة تماماً للأرشيف القديم: https://alelm.net/{section}/{id}/{slug} مما يضمن استمرار تدفق زوار Google دون أي انقطاع.
طبقة التحويلات 301 الذكية Wildcard 301
قاعدة «المعرّف ID يحسم»: أي طلب يطابق /*/:id/* يتم التعرف عليه وتوجيهه فوراً بتحويل 301 دائم إلى مساره الصحيح.
ضمان البيانات المهيكلة (Schema JSON-LD) وخرائط الموقع: توليد تلقائي لمخططات NewsArticle و BreadcrumbList لكل مادة لتعزيز الترتيب في Google News، مع خريطة موقع لحظية sitemap-news.xml للأخبار خلال 48 ساعة.
