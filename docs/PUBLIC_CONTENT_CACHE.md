# كاش المحتوى العام

تُكاش قراءات المحتوى المنشور في Next Data Cache لمدة خمس دقائق، وشريط الأخبار
لمدة 30 ثانية. يرتبط الجميع بالوسم `public-content-v1`، مع استمرار كاش الصفحات ISR.
الجلسات والصلاحيات والمسودات لا تدخل هذا الكاش.

بعد نجاح النشر أو اعتماد تعديل أو الأرشفة أو تغيير إظهار سلسلة، تُبطل البيانات
فورًا باستخدام `revalidateTag(tag, { expire: 0 })` وتُبطل الصفحات المرتبطة.
النشر المجدول يستخدم الإبطال نفسه عند تنفيذ عامل الجدولة. حفظ مسودة المراجعة
لا يغيّر المادة المنشورة قبل اعتمادها.

طلبات API العامة تعيد `public, no-cache, must-revalidate`؛ هذا يتيح حفظ الاستجابة
مع إلزام إعادة التحقق منها، بينما تتولى طبقة الخادم توفير البيانات المخزنة.
إبطال Next لا يمس نسخة مستقلة مخزنة في CDN أو تطبيق الجوال. كذلك صُفّرت مدة
إعادة استخدام صفحات prefetch في Router Cache حتى يراجع التنقل الجديد الخادم.

المقصود بالفورية: أول طلب جديد بعد نجاح النشر. الصفحة المفتوحة دون تنقل أو
تحديث لا تستقبل دفعًا لحظيًا؛ شريط الأخبار ونهر الرئيسية يحتفظان باستطلاعهما
الحالي. الرجوع والتقدم في سجل المتصفح قد يستعيدان الصفحة السابقة.

خريطة الموقع تُقرأ في شرائح من 1000 رابط حتى تبقى كل قيمة دون حد Data Cache
البالغ 2 MB. يمنع عدّاد مشترك داخل عملية الخادم أن يعيد استعلام بدأ قبل النشر
تخزين نتيجة قديمة بعده؛ يعاد الاستعلام إذا تزامن مع إبطال الكاش.

## التشغيل والتحقق

- يستخدم التنفيذ كاش Next الافتراضي لعملية خادم واحدة. تشغيل عدة نسخ/عمليات
  يتطلب Cache Handler مشتركًا وتنسيق الإبطال بينها قبل التوسع.
- لا تُفعّل قاعدة CDN تخزن HTML أو استجابات المحتوى باستقلال عن الأصل دون
  ربط مسحها بمسار النشر. فحص `alelm.net` في 2026-09-05 أعاد `cf-cache-status: DYNAMIC`.
- الكتابة المباشرة إلى قاعدة البيانات أو سكربتات الاستيراد تتجاوز مسارات النشر؛
  تحتاج إبطالًا من سياق Next أو إعادة نشر بعد اكتمالها.
- `node tests/public-cache.integration.mjs` يبني خادم Next إنتاجيًا معزولًا
  ويختبر إصابات الكاش، والنشر والتحديث والأرشفة وإعادة النشر، والاستعلام المتزامن.
  لا يتصل بقاعدة حية ولا يضيف نقطة اختبار إلى التطبيق.
- اختبار workflow يتحقق من اكتمال 2105 روابط عبر حدود شرائح خريطة الموقع
  واستبعاد المسودات، باستخدام `TEST_DATABASE_URL` معزول.
