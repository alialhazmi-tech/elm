# خريطة الهجرة — من ووردبريس القديم إلى منصة العلم

**التاريخ:** 11 أغسطس 2026 · **المصادر:** لقطات لوحة `dash.alelm.net` من المالك + جرد حي عبر
REST API العام (مفتوح للقراءة — انظر الملاحظة الأمنية آخر الوثيقة).
**الحكم المسبق:** لا حذف ولا تعديل في النظام القديم إطلاقًا — قراءة فقط حتى لحظة القطع.

---

## 1. تشخيص النظام القائم

**البنية:** ووردبريس (خلفية إدارة فقط) تديره وكالة TrendDC، بمحرر Classic وبانٍ Oxygen 4.9.2،
وRank Math SEO، وإضافات مخصصة: Article Stats، وميتابوكس «Featured & Breaking» (عرض في
القسم الرئيسي + شريط العاجل بصلاحية تنتهي — الافتراضي ساعتان)، وحقل ملاحظات، ونوع محتوى
«البرامج»، ونشرة بريدية. الواجهة العامة Next.js منفصلة تقرأ من هذه الخلفية.

**الأرقام (جرد 2026-08-11):**

| المكون | العدد |
|---|---|
| المواد (posts) | **29,069** — منها 25,423 «تم النشر» و930 «معتمد» و869 مسودات |
| الوسائط | **96,959** ملفًا |
| التصنيفات (أقسام) | 16 — أكبرها: أحداث جارية 7386، سياسة 6504، اقتصاد 3938 |
| الوسوم | مئات — منها 14 وسم سلسلة فعليًا والبقية حرة أو ملوثة |
| أنواع المقالات (taxonomy مخصصة) | أخبار 21,709 · إنفوجرافيك 6,675 · فيديو 679 · تقارير 75 · بودكاست 4 · جاك العلم 0 |
| حالة المقال (taxonomy مخصصة) | سير عمل تحريري: تم النشر / معتمد / مسودة / للتعديل (بنسختين EN/AR قديمتين) |

**نموذج المحتوى القائم فعليًا** (وإن لم يُسمَّ كذلك): المادة تحمل **أربعة أبعاد** —
التصنيف = الموضوع، الوسم = السلسلة، «أنواع المقالات» = الشكل، «حالة المقال» = سير العمل.
وهذا يطابق فلسفة نظامنا الجديد تمامًا؛ الفارق أن القديم نفذها بأدوات عامة (وسوم حرة)
فتلوثت: وسوم بعناوين مقالات كاملة، وسوم فارغة، «غير مصنف» مكرر مرتين، سلاسل خاملة.

## 2. نموذج المحتوى الجديد — فصل الأبعاد الأربعة

| البعد | القديم | الجديد |
|---|---|---|
| **الموضوع** | تصنيفات متعددة للمادة الواحدة | `section` — **واحد** لكل مادة |
| **العدسة** | وسم `#سلسلة` ضمن وسوم حرة | `seriesSlug` — كيان أول، واحد اختياري |
| **الشكل** | taxonomy «أنواع المقالات» | `format` — **عمود جديد مقترح** (خبر/إنفوجرافيك/فيديو/تقرير/بودكاست) |
| **سير العمل** | taxonomy «حالة المقال» | `status` (draft / review / scheduled / published) + الحارس |

> **قرار معماري مهم:** اليوم عندنا `section=infographics/videos` يخلط الشكل بالموضوع.
> بإضافة عمود `format` يصبح «إنفوجرافيك عن الاقتصاد» = `section=economy, format=infographic`
> — وهو ما يفعله القديم أصلًا عبر taxonomy الأنواع. قرار المالك مطلوب (البند 10).

## 3. الخريطة حقلًا بحقل

| ووردبريس | منصة العلم | ملاحظة |
|---|---|---|
| `ID` | `stories.id` | **يُحفظ كما هو — مفتاح بقاء الروابط** |

| التصنيف الأساسي | `section` | خريطة البند 4؛ عند تعدد التصنيفات: الموضوعي يغلب الشكلي |
| وسم السلسلة | `seriesSlug` | خريطة البند 5؛ عند تعدد وسوم السلاسل: الأعلى أولوية |
| «أنواع المقالات» | `format` | مباشرة (news/infographics/videos/reports/podcasts) |
| «حالة المقال» | `status` | تم النشر/معتمد ← published؛ مسودة ← draft؛ للتعديل ← review |
| `title.rendered` | `title` | فك كيانات HTML |
| `content.rendered` | `body` | تنظيف HTML ‏Oxygen إلى نص/فقرات نظيفة |
| `excerpt.rendered` | `excerpt` | تجريد الوسوم |
| `featured_media` | `image` + سجل في `media` | البند 7 |
| `date_gmt` / `modified_gmt` | `publishedAt` / `updatedAt` | ISO |
| المؤلف | `authorName` + حساب في `users` | dmostafa وAsalah وMahmoud وOqalawun… بدور editor |
| ميتا «عرض في القسم الرئيسي» | قرار المالك (تثبيت هيرو؟) | البند 10 |
| ميتا «شريط العاجل + الصلاحية» | قرار المالك (العاجل محذوف من الهيدر حاليًا) | البند 10 |
| حقل Notes | سجل التدقيق (حدث `note`) أو عمود ملاحظات | صغير — أيهما قررنا |
| Rank Math (keyword/score) | لا يُهاجَر | عقودنا وحارسنا يقومان مقامه |
| تحويلات Rank Math Redirections | **تُصدَّر وتُدمج في طبقة 301** | تحتاج الوصول الإداري |
| الوسوم الحرة غير السلاسل | لا تُهاجَر (أرشيف جانبي JSON) | ملوثة؛ لا قيمة ملاحية |
| التعليقات | لا تُهاجَر | معطلة فعليًا (0) |
| Pages (Careers…) | صفحات ثابتة في الكود عند الحاجة | أغلبها مسودات مكررة |
| «البرامج» + النشرة البريدية | مرحلة لاحقة بعد جرد خاص | خارج نطاق هجرة المواد |

## 6. الوسائط — 96,959 ملفًا

- **الوجهة:** R2 (`media` عندنا) بمسار UUID قصير + نسخ WebP — يُنفذ حين تتوفر بيانات Cloudflare؛
  وحتى ذلك الحين تبقى روابط `wp-content` القديمة تعمل كما هي (لا كسر).
- **الحقوق:** المهاجَر يُعلَّم `rights=legacy` (منشور سابقًا على مسؤولية المرحلة القديمة) حتى
  لا يعلق 97 ألف ملف في التوثيق اليدوي؛ قاعدة §12 تسري بصرامتها على **الجديد فقط**.
- لا يُهاجَر إلا المستخدم فعليًا في مادة (featured أو داخل المتن) — الجرد سيكشف اليتيم.

## 7. الروابط — أهم باب في الوثيقة

**الاكتشاف الحاسم:** بنية روابط القديم `‎/{category}/{id}/{slug}` — **وهي بنية منصتنا نفسها
حرفيًا**، ومفتاحها `ID` الذي نحفظه كما هو. أي أن أغلب الأرشيف لن يحتاج حتى تحويلًا.

الضمانات الثلاث:

1. **الهوية:** نحفظ ID وslug والقسم الأساسي ← الرابط الجديد = القديم بايتًا ببايت.
2. **التحويل بالمفتاح:** طبقة 301 قاعدتها «الـID يحسم»: أي طلب `‎/*/{id}/*` بقسمٍ أو slug
   مختلف (مادة تعدد تصنيفها أو تغير قسمها) يتحول 301 إلى الرابط القانوني. + دمج تصدير
   Rank Math Redirections القائم + تحويلات `‎/tag/{سلسلة}` ← `‎/series/{slug}`.
3. **الإثبات قبل القطع:** زحف آلي لكل روابط خرائط الموقع القديمة (وGSC) — بوابة الإطلاق
   تشترط 100%‏ إما 200 مباشرة أو 301 لوجهة 200، وتقرير فروقات صفري.

## 8. مراحل التنفيذ

| المرحلة | العمل | الاعتماد على |
|---|---|---|
| M-0 | محول قراءة `wp-adapter` فوق REST العام + جرد آلي كامل (مواد/وسائط/فروقات) | متاح الآن — لا يحتاج بيانات دخول |
| M-1 | بروفة هجرة 500 مادة إلى جداولنا + فحوصات (روابط/عناوين/صور/حارس) | M-0 |
| M-2 | الهجرة الكاملة دفعات + فهرس فروقات + إعادة الفحص | M-1 |
| M-3 | طبقة 301 + خرائط الموقع + أرشيف الوسائط إلى R2 | بيانات Cloudflare |
| M-4 | تجميد تحرير قصير في القديم → فرق الدلتا → القطع → مراقبة GSC أسبوعين | قرار المالك |

## 9. قرارات مطلوبة من المالك

1. **عمود `format`** لفصل الشكل عن الموضوع (يوصى به بقوة).
2. **الأقسام الثلاثة الجديدة** current-events / world / ksa (يوصى بإضافتها حفاظًا على الروابط).
3. **السلاسل المتقاعدة** (قالوا/تقارير/موثق/المونديال/ماذا بعد): أرشفة صامتة أم صفحات أرشيف؟
4. **العاجل والتثبيت**: هل نعيد «شريط العاجل بصلاحية» و«التثبيت في الرئيسية» كميزات في
   تحرير العلم؟ (القديم يملكهما، وهيدرنا الحالي بلا شريط عاجل بقرارك).

## 10. ملاحظة أمنية تُبلَّغ للوكالة

REST API العام في `dash.alelm.net` مفتوح بالكامل للقراءة (مواد، تصنيفات، أنواع، حالات سير
العمل، وغالبًا المستخدمون) — وهو ما يخدم الجرد والهجرة الآن، لكنه يكشف بنية العمل التحريري
لأي أحد. بعد اكتمال القطع يُغلق أو يُقيد. كذلك تنبيهات Oxygen الظاهرة في اللوحة تشير إلى
كاش CSS غير مجدد — شأن الوكالة، لا يؤثر على الهجرة.
