# إعادة فحص قائمة التدقيق الأصلية

وصل ملف التدقيق في متابعة المستخدم، وكشف الرابط في `Sheet1!B7` عن [CSV الأصلي في Google Drive](https://drive.google.com/file/d/1SO21j-1aV4Mm7YaWta8uEjJ0MdmYNg5S/view?usp=sharing). الملف هو تصدير **الأوصاف التعريفية المكررة** بتاريخ 13 سبتمبر، رغم وضع رابطه تحت بند العناوين في Excel. يحتوي 848 رابطًا فريدًا، منها 807 بروابط صفحات الأرشيف ذات query string. لا يحتوي قائمة مستقلة للحالات الثماني للعناوين. بيانات المصدر وبصمته في [source.json](source.json)، والنص الأصلي بعد توحيد نهايات السطور في [source-meta-descriptions.csv](source-meta-descriptions.csv).

أُعيدت طلبات GET عامة، بحد أقصى طلبين متزامنين، يوم 13 أكتوبر **15:56:19–16:02:28 بتوقيت السعودية**. لم تتغير بيانات الموقع أو كوده أثناء هذا الفحص. [القائمة المستخدمة](urls.txt) كاملة، وليست عينة sitemap الجديدة ذات 159 صفحة.

| النتيجة بعد إعادة المحاولة الموثقة | العدد |
|---|---:|
| الروابط الأصلية المطلوبة | 848 |
| صفحات 200 مباشرة | 847 |
| تحويل 308 واحد ينتهي إلى 200 | 1 |
| عناوين / أوصاف / canonical مفقودة | 0 / 0 / 0 |
| مجموعات عناوين / أوصاف / canonical مكررة | 0 / 0 / 0 |
| روابط email-protection في HTML المفحوص | 0 |
| تعذر فتح غير محسوم | 0 |

[نتائج جميع الروابط بعد التحقق](verified-crawl.csv) و[الملخص](verified-summary.json). حساب التكرار يقتصر على صفحات 200 المباشرة، وعددها 847؛ لا نعد رابط التحويل صفحة مستقلة مكررة. المقارنة نصية تامة بعد فك HTML entities، وليست تحليلًا دلاليًا لتشابه المحتوى. هذا تحقق من HTML المتاح للزائر، وليس إثباتًا لتحديث فهرس Google لكل رابط.

**التحويل المتوقع:** `/world/1658/…-2` يحوّل 308 مرة واحدة إلى `/world/1660/…`، والوجهة 200 وcanonical مطابق. لم نعدّل السجلين أو الرابطين.

**الانقطاع العابر:** الجولة الأولى سجلت `RemoteDisconnected` لرابط `/series/matha-baad?p=9`؛ لم تُحوّل النتيجة إلى نجاح أو تُحذف. [crawl.csv](crawl.csv) و[summary.json](summary.json) يحفظان المحاولة الأولى: 846 صفحة 200 مباشرة وتحويل 308 واحد وانقطاع واحد. [transport-retry.json](transport-retry.json) يحفظ طلبًا مستقلًا عند 16:01:45؛ عاد 200 بوصف وعنوان وcanonical فريدة. `verification_attempt=2` يميّز هذا الصف وحده في الملف المجمّع.

إعادة التشغيل:

```sh
python3 scripts/audit-original-seo.py \
  --csv audit/2026-10-13/seo-original/source-meta-descriptions.csv \
  --out audit/new-run/original-list
```

الأداة لا تعيد المحاولة تلقائيًا. إذا حدث انقطاع، احتفظ بنتيجة الجولة الأولى وأعد فحص الرابط منفصلًا كما في هذه الجولة. لا حاجة إلى تغيير الكود للأوصاف أو العناوين بناءً على النتيجة الحالية. بند الأوصاف في القائمة الأصلية **تم التحقق دون تعديل**؛ المطابقة المستقلة للحالات الثماني للعناوين تبقى لدى فريق SEO حتى تحديد روابطها، ثم يراجعها المطور خلال 4 ساعات عمل من الاستلام.
