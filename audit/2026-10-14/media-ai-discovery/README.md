# تعريف الفيديو والبودكاست للمساعدات ومحركات البحث

**التاريخ:** 14 أكتوبر 2026، بتوقيت السعودية. هذه متابعة تقنية لدفعة [PR #37](https://github.com/salkhaldi/elm/pull/37)، بعد طلب المالك استكمال العمل والسماح للمساعدات، مع تأجيل تغييرات Cloudflare و«جاك العلم».

## المشكلة والنتيجة

المقال العادي يرسل نصه وبياناته من الخادم بالفعل. لكن عينات الفيديو كانت تعرّف نفسها كمقال فقط، وصفحات برامج البودكاست كانت تصف البرنامج باعتباره خبرًا. تضيف هذه الدفعة تعريفًا مطابقًا لنوع الوسائط التي تعرضها الصفحة، لتسهيل فهمها وربطها بمصدرها وروابطها الأصلية.

| التعديل | ما الذي يقدمه؟ |
|---|---|
| `VideoObject` | اسم الفيديو ووصفه ورابط المشغّل والصورة التحريرية المعتمدة للمادة وتاريخ نشره على الموقع، مرتبطًا بالمقال الأصلي. يقتصر على تضمين YouTube في قالب الفيديو، وببيانات مكتملة تتضمن الصورة. |
| `PodcastSeries` و`PodcastEpisode` | تعريف البرنامج وحلقاته المعروضة في HTML، وربطها بهوية «العلم»، مع روابط الصوت الحقيقية والمدد والتواريخ المتاحة. |
| روابط الحلقات | رابط ثابت لكل حلقة داخل صفحة البرنامج، لا يتغير لمجرد إعادة ترتيب الحلقات. |
| فحص قابل للإعادة | أداة قراءة فقط تحفظ نفس عينة الصفحات للمقارنة، وتختبر وجود العناوين وروابط المشغّل والحلقات التي تصفها البيانات المنظمة. |

تاريخ `uploadDate` هو تاريخ نشر المادة على «العلم» الظاهر للقارئ، وليس ادعاءً بمعرفة تاريخ رفعها الأول إلى YouTube. لم تُضف مدة فيديو أو تفريغ أو مالك حقوق أو اسم كاتب بالتخمين. تبقى بيانات المقال والناشر قائمة بجانب الفيديو؛ صفحات البرامج تستخدم تعريف البرنامج بدل `NewsArticle` غير المطابق لمحتواها. لا يُستنتج أن منشور X أو Instagram فيديو؛ لا يُضاف له هذا التعريف دون بيانات تثبت ذلك.

الملفات الأساسية: `lib/seo/media.ts`، قالب المادة `app/[section]/[id]/[slug]/page.tsx`، مكوّنا عرض وتشغيل البودكاست، ومسار `app/podcasts/[slug]/page.tsx`.

## الاختبارات والأدلة

- `npm test`: نجح البناء وTypeScript وlint وميزانية JavaScript وجميع **486 اختبارًا**، منها 7 اختبارات جديدة للوسائط.
- `node tests/indexing-runtime.integration.mjs`: نجح فحص Next المبني محليًا: الروابط والخرائط وبيانات المقال والناشر والمسارات وRSS ودليل المساعدات.
- اختبار العرض الفعلي من الخادم يتحقق من تطابق الحلقة مع اسمها المرئي ورابطها والصوت والمدة، ومن سلامة النص الذي يحتوي محاولات إغلاق وسم `script`.
- [عينة الإنتاج قبل التحديث](before.json): **19 صفحة أعادت 200** عند 00:29، منها 5 مقالات و3 فيديوهات و4 برامج بودكاست. الفيديوهات والبرامج كانت تحتوي `NewsArticle` دون تعريف الوسائط المطلوب.
- فحص الموارد قبل الدمج: صورتا المادتين 300269 و264578 أعادتا 200. مادة [تقنيات التواصل أمام الصم](https://alelm.net/technology/300181/تقنيات-حديثة-تكسر-حواجز-التواصل-أمام-الصم) لا توفر صورة تحريرية، وصورة تضمينها وواجهة YouTube oEmbed للرابط `rVY9rVEcngM` أعادتا 404؛ لا نختلق لها صورة ولا نضيف `VideoObject` ناقصًا. يلزم التحرير مراجعة رابط الفيديو والصورة. اكتمال HTML لا يثبت توفر الفيديو عند المزود.
- قياسات طلبات HTTP في التقرير ليست اختبار أداء جوال. عدد كلمات `main` يشمل عناصر التحكم والروابط، ولا يمثل طول متن المقال وحده.
- CI واختبارات التكامل مع PostgreSQL تظهر في طلب الدمج. لا يُعد الفحص المحلي إثباتًا لتطبيق التحديث على الإنتاج؛ تُضاف نتيجة المقارنة بعد النشر إلى طلب الدمج.

لإعادة الفحص بنفس الروابط:

```sh
node scripts/audit-ai-discovery.mjs --manifest audit/2026-10-14/media-ai-discovery/before.json --out tmp/media-after.json
# إضافة --bots تشغّل محاكاة أسماء الزواحف على robots والدليل ومقال واحد.
```

## الوصول وسياسة المالك

اعتمد المالك الرغبة في السماح لأنظمة الذكاء الاصطناعي، وأجّل مراجعة Cloudflare وتعديلاته. لم يتغير جدار الحماية أو robots أو إعداد الاستضافة في هذه الدفعة.

في عينة المحاكاة نجحت الأسماء التالية على المسارات الثلاثة: `OAI-SearchBot` و`ChatGPT-User` و`Claude-SearchBot` و`Claude-User` و`PerplexityBot` و`Perplexity-User` و`Googlebot`؛ أي 21 طلبًا ناجحًا. نجح `GPTBot` أيضًا في هذه العينة، بينما أعاد `ClaudeBot` استجابة 403 للدليل والمقال. اختبار الاسم وحده لا يثبت مرور الزواحف الحقيقية من شبكاتها ولا يكشف قاعدة المنع الفعلية. لا ندّعي أن جميع أنظمة الذكاء الاصطناعي أصبحت مسموحة؛ توحيد الإعدادات والتحقق من الطلبات الفعلية بند مؤجل إلى مراجعة Cloudflare.

## ما اكتمل وما بقي؟

| البند | الحالة والمسؤول |
|---|---|
| دليل `llms.txt` وRSS وربط هوية المصدر | منشور ومتحقق منه في PR #37؛ مسؤولية التقنية إبقاء روابط الدليل متسقة مع الموقع. |
| تعريف الوسائط وروابط الحلقات | أُنجز واختُبر في هذه الدفعة؛ يكتمل إثبات الإنتاج بعد الدمج والنشر. |
| وصول كل الزواحف الحقيقية | مؤجل لمراجعة Cloudflare مع التقنية؛ السياسة المطلوبة السماح، ولا يوجد موعد نشر لهذا التغيير بعد تأجيله. |
| نصوص الفيديو والبودكاست ومصادرها | تنتظر التحرير. محرر المقال يدعم المتن والروابط والعناوين ويعرضها في HTML بالفعل؛ تستخدم الإمكانات القائمة أولًا. وصف الحلقة الحالي ليس تفريغًا كاملًا. إن تقرر نشر تفريغ طويل للحلقات نجهز معاينة عرض مستقلة بعد استلام نموذج. |
| أسماء الكتّاب والسياسات والتعريف بالفريق | تنتظر مواد التحرير المعتمدة؛ لا ننشر أسماء حسابات CMS تلقائيًا. |
| «جاك العلم» | مؤجل بطلب المالك وخارج هذه الدفعة. |
| تحسن الإحالات والاستشهادات | خُصص له [بروتوكول قياس ثابت](measurement.md). الأثر يحتاج متابعة بعد إعادة الزحف؛ لا تُعد زيارات Analytics عددًا للاستشهادات. |

## المخاطر والتراجع

التغيير في بيانات JSON-LD التي يرسلها الخادم ومعرّفات عناصر الحلقات؛ لا يضيف استعلام قاعدة بيانات أو اتصالًا بمزود خارجي. الحجم الإضافي يتناسب مع عدد الحلقات التي كانت تعرضها الصفحة بالفعل. لم تتغير الشاشات أو التصميم أو المشغّل أو صلاحيات النشر أو جلسات الدخول أو قاعدة البيانات.

يمكن التراجع بإلغاء commit هذه الدفعة وإعادة النشر، أو استعادة نشر PR #37 في Railway عند الحاجة. لا توجد هجرة قاعدة بيانات أو إعدادات خارجية يلزم عكسها. روابط المقالات والبرامج القديمة ثابتة؛ التراجع يزيل معرّفات الحلقات الجديدة فقط.

هذه البيانات تسهل الفهم والاكتشاف، ولا تضمن أن أي مساعد سيستشهد بالصفحة. مراجع التنفيذ: [VideoObject](https://schema.org/VideoObject)، [PodcastSeries](https://schema.org/PodcastSeries)، [PodcastEpisode](https://schema.org/PodcastEpisode)، [إرشادات Google للفيديو](https://developers.google.com/search/docs/appearance/structured-data/video).
