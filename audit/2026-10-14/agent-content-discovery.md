النطاق المعتمد: التحسينات الخمسة المناسبة لموقع العلم، في PR واحد للمراجعة. هذه وثيقة تنفيذ واختبار؛ لا تعني أن التعديلات نُشرت أو أن محركًا بدأ الاستشهاد بالموقع.

## التعديلات

| البند | التنفيذ | التحقق |
|---|---|---|
| Link response headers | الرئيسية تعلن `api-catalog` و`service-doc` و`service-desc` و`describedby` بروابط حقيقية | اختبار HTTP يقرأ الترويسة، ويجلب ملفاتها بأنواع المحتوى الصحيحة |
| Content Signals | السماح بـ `search` و`ai-input` و`ai-train` في robots؛ تظهر أيضًا على ردود Markdown وAPI | اختبار الملف المنشور وترويسات الاستجابة؛ يستمر منع بقية `/api/` من الزحف |
| Markdown عند الطلب | الرئيسية والقالب العام للأخبار، بطلب صريح `Accept: text/markdown` | أوزان `q`، GET وHEAD، العربية والعناوين والقوائم والمصادر، HTML الافتراضي، وحماية الأصل |

| Agent Skills | مهارة `read-alelm` وفهرس الاكتشاف v0.2.0 | تطابق الاسم والوصف وبصمة SHA-256 مع بايتات الملف |

## قرار واجهة القراءة

واجهات التطبيق القائمة تستخدم الرجوع إلى محتوى تجريبي في بعض أعطال مصدر البيانات. لذلك لا يعلن هذا الفهرس عن واجهات الحسابات أو يغيّر عقود تطبيق الجوال؛ أُضيف مسار قراءة عام محدود في `/api/content/v1`، يعتمد على نفس قاعدة المحتوى وكاش النشر الحالي:

- `/search?q=...&page=...`: 20 مادة في الصفحة، حد أقصى 200 نتيجة، واستعلام حتى 200 محرف. `capped` يوضح وجود نتائج إضافية.
- `/articles/{id}`: حقول عامة محددة، متن منقّى إلى Markdown، وروابط المصدر والمعرّف العام والرابط المعتمد.
- `status=published` شرط لازم، مع استبعاد إصدارات المراجعة والمستقبل والمواد بلا تاريخ نشر والأسماء البديلة المكررة وتقارير «جاك العلم» التفاعلية.
- خطأ المصدر يعيد 503 مع `Retry-After` و`no-store`، دون نشر محتوى تجريبي أو تفاصيل قاعدة البيانات.
- JSON الخاص بالتحقق التحريري يقتصر على `rumor` و`truth`، دون مفاتيح إضافية.

الرئيسية النصية تستخدم تركيب المختارات التحريرية نفسه. النص لا يشمل أدوات الحساب والتفاعلات، ولا يدّعي توفير تفريغ للفيديو أو الصور أو الصوت. صفحات الأقسام والبحث والبودكاست التفاعلي خارج تحويل Markdown بهذه الدفعة.

## حماية التوجيه والكاش

حارس الأصل يعمل قبل التفاوض. يحذف Proxy ترويسة المسار إن أرسلها العميل، ثم ينشئها فقط لطلب Markdown المؤهل. يستخدم Next إعادة كتابة نسبية داخل التطبيق، فلا يعيد الطلب إلى حارس الأصل أو يرسل ترويسة الأصل إلى عميل خارجي.

تُضاف `Vary: Accept` مع الحفاظ على ترويسات Next، وMarkdown يعاد بـ `Cache-Control: private, no-store`. HTML يبقى افتراضيًا؛ الزيارات العادية وطلبات Next/RSC لا تتغير. حالات GET وHEAD وwww والاستعلامات واختلاق ترويسة المسار تدخل في اختبار HTTP. لا تُقبل عناوين خارجية للتحويل، ولا تُنفذ طلبات جلب يختارها العميل.

فحص الإنتاج قبل هذه الدفعة أظهر `CF-Cache-Status: DYNAMIC` للرئيسية مع HTML وMarkdown؛ كانت النسختان HTML، دون Link أو Content-Signal. تبقى إعادة التحقق عبر Cloudflare مطلوبة بعد النشر.

## الفحوص القابلة للتكرار

```sh
npm test
npm run test:integration
node tests/rss.integration.mjs
node tests/agent-content.integration.mjs
node tests/agent-runtime.integration.mjs
```

اختبارات قاعدة البيانات تتطلب `TEST_DATABASE_URL` لقاعدة محلية معزولة يبدأ اسمها بـ `alelm_test`؛ لا تعمل على قاعدة الإنتاج. بوابة CI تشغّل هذه الفحوص. اختبارات الوحدة الحالية تشمل 491 اختبارًا بعد إضافة هذه الدفعة. يُوثق رابط تشغيل CI ونتيجته في PR بعد الرفع.

اختبار التكامل يزرع مواد منشورة ومسودات ومراجعات ومؤرشفة ومستقبلية ومواد بلا تاريخ، ثم يتحقق من الفلترة والحدود والروابط العربية وسحب المادة وفشل التخزين. اختبار HTTP يستخدم بناء الإنتاج مع قاعدة مفصولة عمدًا: المتوقع 503 للقراءة النصية، وليس نجاحًا بمحتوى تجريبي. نجاح القراءة نفسها يُختبر على PostgreSQL معزول ومهاجر.

## تحقق الإنتاج بعد الموافقة والنشر

1. GET وHEAD للرئيسية: Link موجود وروابطه تعمل؛ HTML ما زال افتراضيًا.
2. طلب Markdown للرئيسية ومادة خبر فعلية: 200، `text/markdown`، `Vary: Accept`، `private, no-store`، رابط معتمد ومحتوى عربي صحيح. إعادة طلب HTML للتأكد من عدم خلط الكاش.
3. البحث عن خبر وقراءته عبر API؛ التأكد من جاهزية المصدر وعدم ظهور بيانات حسابات.
4. ملفات الفهرس وOpenAPI والمهارة وrobots، مع مقارنة بصمة المهارة.
5. طلب غير موثق على أصل Railway يظل مرفوضًا، بينما `/api/health` يصل إلى فحص الجاهزية.
6. إعادة فحص isitagentready إن أتاح الخدمة. محاولة `POST https://isitagentready.com/api/scan` قبل النشر أعادت HTTP 403، رمز الخدمة 1010؛ لذلك لا توجد نتيجة `checks.discoverability.linkHeaders.status=pass` من هذه الأداة بعد الإصلاح حتى الآن. لا يُستعاض عن ذلك بادعاء اجتياز خارجي.

## المخاطر والتراجع

الخطر الأساسي هو توافق التفاوض والكاش بعد المرور بالحافة، إضافة إلى عبء طلبات البحث العامة. الردود النصية تمنع الكاش الوسيط، وقراءات المقالات ومختارات الرئيسية تستخدم كاش المحتوى الحالي وإبطاله عند النشر. البحث محدود النتائج ولا يرجع المتن ضمن القوائم. لا يتضمن التغيير ضمانًا ضد إساءة استخدام طلبات البحث؛ يمكن متابعة حجمها وتطبيق حدود مناسبة عند الحاجة.

التراجع: revert لالتزام هذه الدفعة وإعادة نشره، أو استعادة نشر Railway السابق مؤقتًا ثم مزامنة Git. لا توجد هجرة قاعدة بيانات أو إعدادات DNS أو Cloudflare أو تعديل على جلسات الدخول أو التصميم.

البنود خارج النطاق المعتمد: OAuth/OIDC وProtected Resource Metadata وauth.md وخادم MCP وDNS-AID وWebMCP وARD. لا ننشر بيانات تعريف لخدمات غير موجودة.
