# تطبيق العلم — iOS

SwiftUI، iOS 17+. الهوية من `app/soft.css` والشعار الرسمي. التوثيق: [`docs/ios/HANDOFF.md`](../docs/ios/HANDOFF.md).

```
open ios/Elm.xcodeproj
```

## دليل السلاسل بالطبعة التحريرية — 2026-09-17

قائمة بعمود واحد بدل شبكة البطاقات الفارغة: شرطة بلون السلسلة، الاسم بخط العرض 20، الوصف، عدد المواد وآخر مادة،
وخطوط تفاصيل بين الصفوف. أُزيل شريط الطيف والنقاط الملوّنة، وأرشيف السلاسل المتقاعدة قسم مسطّح بعنوان تحريري.

## قارئ المادة بالطبعة التحريرية — 2026-09-17

رأس مضغوط: كيكر بشرطة السلسلة، عنوان 25، الموجز التحريري بثلاثة أسطر مع «الموجز كاملًا»، سطر بيانات واحد (الكاتب،
التاريخ بتوقيت الرياض، وقت القراءة) وبجانبه زر «استمع للموجز» المضغوط. لا شريط دائم أسفل القارئ: `ReaderAudioBar`
يظهر أثناء التجهيز/التشغيل فقط (شريط زمني، توقيت، نسبة HUMAIN)، وخيارات القراءة (حجم الخط، القراءة بصوت الجهاز) في
قائمة «⋯» بالرأس. الأقسام السفلية بعناوين موحّدة فوق خط بنية بدل البطاقات المحدودة.

## جاهزية TestFlight — 2026-09-17

الإصدار 1.0.0 (1)، أيقونة رسمية بثلاث نسخ (فاتح/داكن/ملوّن) مولّدة من `ios/scripts/make-app-icon.py`، أصل الإنتاج
`https://alelm.net` بعد أن صار أصل Railway المباشر يرفض الطلبات، وبيان خصوصية مكتمل. الأرشفة والرفع عبر
`ios/scripts/archive.sh --upload`. التفاصيل وما يبقى على المالك: [`docs/ios/TESTFLIGHT.md`](../docs/ios/TESTFLIGHT.md).

## تجربة التطبيق واتساق الوظائف — 2026-09-06

الرئيسية يومية بثلاث زوايا للقراءة: اليوم، وراء الخبر، مرئي وبيانات. تبويب استكشف يجمع السلاسل والأقسام والوسائط؛ تبويبات البحث ولك أنت والحساب مستقلة. الحفظ والمشاركة مباشرة من البطاقات، والموجز في شاشة مستقلة. الهوية والخطوط متسقة مع الويب، والتخطيط مصمم للتطبيق.

الأقسام والسلاسل تستخدم `/api/mobile/v1/browse` بترقيم SQL مشترك مع الويب. خدمة التفاعل الحالية `/api/content/interactions` تدعم الإعجاب واستفتاء الختام بنفس الخيارات والنتائج؛ لا تستخدم أصوات الجهاز القديمة. البودكاست وتشغيل الفيديو والصفحات العامة تفتح الموقع داخل Safari المضمّن. يلزم نشر إضافات API قبل إصدار التطبيق؛ التغييرات محلية حاليًا.

التوثيق والفحص وحدود التكافؤ: [`docs/ios/DESIGN-REVIEW-2026-09-06.md`](../docs/ios/DESIGN-REVIEW-2026-09-06.md).

## التسليم السابق — 2026-08-13

- شاشات 1a–1m مكتملة: الرئيسية، السلاسل، المادة، البحث، «لك»، الحساب، العضوية الأصلية، الاهتمامات، المحفوظات، الإعدادات، المشغل الصوتي، وحالة بلا اتصال.
- العضوية تتصل مباشرة بـ Neon Auth وتحفظ جلسة HTTPS في `HTTPCookieStorage`.
- حزمة الرئيسية وتفاصيل المواد المفتوحة محفوظة عبر SwiftData، مع هجرة من كاش JSON القديم.
- RTL وDynamic Type وVoiceOver مدعومة؛ جرى التحقق على iPhone 17 Pro وiPhone 17e.
- WidgetKit وStoreKit خارج هذا التسليم ولم يُدّعَ اكتمالهما.

## تحقق سريع

```sh
xcodebuild -project ios/Elm.xcodeproj -scheme Elm -configuration Debug \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  CODE_SIGNING_ALLOWED=NO build
```
